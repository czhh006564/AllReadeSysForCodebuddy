「已陪伴 X 名小读者」是永久图书价值的核心表达：一册书在生命周期内持续被不同学生阅读，价值随时间累积。
「投放次数」与「完整循环次数」口径不同：一次投放对应一个班级轮次，而一次完整循环要求该批图书已回收并归仓、可再次投放，二者不可混用。
